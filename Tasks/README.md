## TDRC task portfolio

This folder records benchmark and application-oriented tasks for the SBS-enhanced OEO time-delay reservoir computer.

| Task | Primary purpose | Relationship to the platform |
|---|---|---|
| [[Tasks/Nonlinear_Channel_Equalisation]] | Established baseline task. | Demonstrates nonlinear temporal equalisation. |
| [[Tasks/Mackey_Glass_Prediction]] | Delayed nonlinear prediction benchmark. | Tests memory and delay. |
| [[Tasks/Lorenz_63_Prediction]] | Chaotic-system prediction benchmark. | Tests nonlinear state reconstruction, forecasting, and multivariate input. |
| [[Tasks/Multivariate_Time_Series_Prediction]] | General framework for joint-variable forecasting and control. | Connects multichannel physical processing to richer real-world inputs. |

The task portfolio supports the proposal's broad application-discovery strategy. It should not be treated as a promise to complete every task. The 18-month PoC will select the subset that best demonstrates the platform's new SBS-enabled capabilities and supports engagement with external partners. See [[Project_Memory#G-002 — Grant duration and external-engagement target]].
