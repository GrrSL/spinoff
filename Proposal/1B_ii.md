## Section 1b.ii — Activities Exploring the Pathway from Research towards Innovation

### Activity 1 — Validate the SBS-enabled computational platform

The project will establish the SBS-enhanced OEO as a configurable time-delay reservoir computer. It will characterise the operating conditions required for stable nonlinear dynamics, temporal memory and task-relevant signal transformation. The work will focus on the new capabilities introduced by SBS: pump-controlled dynamical regimes, parallel wavelength channels and exploratory pump-programmed input masking.

Success will be judged by the ability to operate the platform reproducibly and to select physical settings that improve a defined computational task. The work will turn existing experimental light–sound dynamics into a controllable computational resource.

### Activity 2 — Demonstrate temporal-processing capability

The project will evaluate the platform on a portfolio of demanding temporal tasks:

- **Nonlinear Channel Equalisation** will provide continuity with the existing experimental baseline and test nonlinear temporal processing on a communications-relevant signal.
- **Chaotic time-series prediction** using Lorenz-63 and Mackey–Glass will test memory, nonlinear state reconstruction, multi-step forecasting and autonomous prediction.
- **Multivariate time-series prediction** will test whether several synchronised variables, or several physical representations of the same signal, improve prediction accuracy, forecast horizon or a compact control-relevant output.

The computational portfolio will be used strategically. It will identify the operating conditions in which SBS-enabled control provides a benefit and will support credible comparison of different dynamical regimes and channel configurations. It will also create demonstrable capabilities that can be discussed with prospective application partners.

### Activity 3 — Demonstrate parallel and adaptive processing

The project will demonstrate multichannel operation through parallel temporal tasks and will investigate how pump configuration can tune the computational dynamics of each channel. This will test two routes to increased value: simultaneous processing of independent streams and complementary processing of the same stream under different physical conditions.

Pump-programmed masking will be explored as an additional route to task-specific configuration. Its purpose is to test whether a physical control of the input transformation can complement the trained linear readout. This activity is exploratory; the PoC's core success does not depend on replacing the conventional mask in every operating mode.

### Activity 4 — Engage end users and identify application requirements

The project will conduct structured discovery with prospective industrial and societal partners. The aim is to identify real signal-processing bottlenecks, the availability of native analogue optical inputs, and the value of compact outputs such as a decision, feature vector or control signal.

The initial end-user assessment covers four complementary groups:

| End-user group                                                                              | Potential need                                                                                                                      | Potential value of the platform                                                                                       |
| ------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Industrial laser-processing and manufacturing organisations                                 | Early identification of unstable welding or material-processing regimes; quality monitoring and future closed-loop control.         | Transform reflected-light or process-emission dynamics into a compact warning or control signal.                      |
| Radar, phased-array and analogue radio-over-fibre system developers                         | Event detection, interference classification, state estimation or signal-quality monitoring before full-rate electronic processing. | Process analogue intermediate-frequency or sub-band optical signals and reduce downstream processing burden.          |
| LiDAR, robotics and autonomous-vehicle developers                                            | Optical ranging produces high-volume dynamic sensor information that must support perception, tracking and control.                 | Perform a defined optical pre-processing, detection or classification task before the main electronic perception stack, reducing downstream compute and energy burden. |
| Distributed fibre-sensing instrument developers and infrastructure-monitoring organisations | Event classification, anomaly detection and prediction from fibre-derived temporal signals.                                         | Add temporal processing close to an intrinsically optical sensing workflow.                                           |
| Photonic-component, optical-system and integration partners                                 | Configurable signal processing within future optical instruments or accelerators.                                                   | Provide the components and system-integration route needed to turn a laboratory platform into a compact demonstrator. |

The project will not assume that every group becomes a customer. Instead, it will use interviews, technical exchanges, application requirements and, where feasible, access to representative data to select the strongest initial market-entry pathway. A letter of support or intent will be sought from engaged stakeholders where appropriate.

### Activity 5 — Clarify intellectual property and exploitation strategy

The project will review the intellectual-property landscape around SBS-enabled reservoir architectures, pump-controlled configuration and potential system-integration concepts. It will identify protectable results, freedom-to-operate questions and the most appropriate route to exploitation.

The preferred route is preparation for spin-off formation. The exploitation plan will define the first application focus, strategic component and integration partners, required follow-on financing, and the transition from laboratory platform to a compact demonstrator. Licensing, collaborative development or research contracts will remain possible complementary routes where they accelerate validation or market access.
