# SBS-Enhanced Photonic Reservoir Computing Spin-off

Working materials for an ERC Proof of Concept proposal based on **SOUND-PC — Computing with Light and Sound**.

The project explores an SBS-enhanced optoelectronic oscillator as a configurable time-delay reservoir computer for direct processing of dynamic analogue optical signals. The long-term aim is to establish a photonic-computing platform that can produce compact predictions, classifications, feature representations, or control signals with reduced downstream electronic processing.

## Repository structure

- `Proposal/` — external-audience drafts of the ERC PoC Part B sections and separate internal drafting notes.
- `Applications/` — application hypotheses, system fit, and causal bottlenecks.
- `Features/` — prospective capabilities of the SBS-enhanced platform.
- `Limitations/` — integration and deployment limitations.
- `Tasks/` — benchmark and application-oriented TDRC tasks.
- `Grant_Structure.md` — Part B preparation checklist derived from the call template.
- `Technical_Specification.md` — technical reference for the current experimental platform.
- `Project_Memory.md` — reusable project statements, assumptions, and directions.
- `Journal.md` — timestamped project decision log.
- `AGENTS.md` — working conventions for maintaining these materials.

## Working conventions

- Repository files are maintained in English for sharing with collaborators.
- Technical details, evidence, and open questions are stored separately from external proposal drafts.
- Markdown notes are structured for use with Obsidian, including Canvas and wikilinks where appropriate.

## Status

This repository contains evolving proposal and project-development materials. It is not a released software package or a final grant submission.
